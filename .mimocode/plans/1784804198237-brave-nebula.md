# خطة إصلاح صفحة إدارة الحساب والإعدادات

## المشاكل المكتشفة

### 1. الحفظ لا يعمل ❌
**السبب**: GET endpoint لا يُرجع `instagramUrl`, `tiktokUrl`, `youtubeUrl` في `select` query.
**الملف**: `src/app/api/users/[username]/profile/route.ts` سطر 17-42
**الحل**: إضافة هذه الحقول لـ `select` query.

### 2. لون الهالة يتداخل مع زر الحفظ ❌
**السبب**: `accentColor` يُستخدم لكل شيء: الأفاتار, الأزرار, الحواف.
**الحل**: استخدام `accentColor` فقط للأفاتار والزخارف، واستخدام لون ثابت (أزرق/رمادي) للأزرار.

### 3. روابط خارجية مكررة ❌
**السبب**: قسم "الحساب" فيه روابط خارجية (Google, Discord) وقسم "تخصيص الملف الشخصي" فيه روابط اجتماعية.
**الحل**: نقل "ربط الحسابات الخارجية" من قسم "الحساب" إلى "تخصيص الملف الشخصي" كقسم "الحسابات الخارجية".

### 4. تصميم الألوان ضعيف ❌
**الحل**: استخدام ألوان ثابتة للأزرار والخلفيات، و`accentColor` فقط للزخارف.

## خطة التنفيذ

### الخطوة 1: إصلاح GET endpoint
**الملف**: `src/app/api/users/[username]/profile/route.ts`

إضافة الحقول المفقودة في `select` query:
```typescript
instagramUrl: true,
tiktokUrl: true,
youtubeUrl: true,
```

### الخطوة 2: إعادة تصميم صفحة الإعدادات
**الملف**: `src/views/settings.tsx`

#### تغييرات التصميم:
1. **ألوان الأزرار**: استخدام `bg-[#3b82f6]` (أزرق ثابت) بدلاً من `accentColor`
2. **ألوان الحواف**: استخدام `border-[#333]` بدلاً من `border-[color:accent]`
3. **تلوين الأفاتار فقط**: `accentColor` يُستخدم فقط حول الأفاتار والزخارف

#### تغييرات الهيكل:
1. **قسم "الحساب"**: حذف "ربط الحسابات الخارجية" منه
2. **قسم "تخصيص الملف الشخصي"**: إضافة قسم "الحسابات الخارجية" في النهاية

#### الأقسام الجديدة في "تخصيص الملف الشخصي":
1. **البانر الخلفي** — رفع + preview + إزالة
2. **الصورة الرمزية** — رفع + preview + إزالة
3. **اسم المستخدم** — حقل editable + التحقق من التكرار
4. **اللون المميز** — color picker + معاينة الهالة
5. **النبذة الشخصية** — textarea
6. **الروابط الاجتماعية** — 7 حقول
7. **الحسابات الخارجية** — Google, Discord (من قسم الحساب)

### الخطوة 3: التحقق من الـ API
**الملف**: `src/app/api/users/[username]/profile/route.ts`

التأكد من أن:
- GET يُرجع كل الحقول
- PUT يقبل كل الحقول
- `username` update يعمل بشكل صحيح

## الملفات المطلوب تعديلها

| الملف | التعديل |
|-------|---------|
| `src/app/api/users/[username]/profile/route.ts` | إضافة instagramUrl, tiktokUrl, youtubeUrl لـ GET select |
| `src/views/settings.tsx` | إعادة تصميم + إصلاح الألوان + نقل الحسابات الخارجية |

## التحقق من التنفيذ

1. `npx tsc --noEmit` — لا أخطاء TypeScript
2. فتح صفحة الإعدادات والتأكد من ظهور كل الحقول
3. تغيير كل الحقول والضغط على "حفظ"
4. التأكد من أن التغييرات محفوظة بعد إعادة التحميل
5. التأكد من أن لون الهالة لا يتداخل مع الأزرار
6. التأكد من عدم وجود روابط خارجية مكررة
