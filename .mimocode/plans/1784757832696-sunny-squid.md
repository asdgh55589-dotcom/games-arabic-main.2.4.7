# خطة إصلاح تسجيل الدخول للبيئة الإنتاجية

## المشكلة:
تسجيل الدخول يعمل في متصفح واحد لكن لا يعمل في متصفح آخر.

## السبب:
1. **Supabase callback URL** مضبوط على `https://games-arabic.vercel.app/api/auth/callback`
2. عندما تسجل دخول على `localhost:3000`، يُحوّل إلىإنتاجي
3. الكوكيز تُحفظ للنطاق الإنتاجي، ليست لـ `localhost`

## الحل:

### الخطوة 1: إضافة localhost إلى Supabase Dashboard
1. ادخل Supabase Dashboard → Authentication → URL Configuration
2. أضف `http://localhost:3000/api/auth/callback` إلى **Redirect URLs**
3. أضف أيضاً `https://games-arabic.vercel.app/api/auth/callback`

### الخطوة 2: تعديل callback route لدعم كلتا البيئتين
**الملف:** `src/app/api/auth/callback/route.ts`

**المشكلة:** الـ redirect يعتمد على `req.url` الذي قد لا يكون صحيحاً.

**الحل:**
```typescript
// تحديد الـ redirect URL بناءً على البيئة
const getRedirectUrl = (req: NextRequest) => {
  const host = req.headers.get('host') || 'localhost:3000'
  const protocol = req.headers.get('x-forwarded-proto') || 'http'
  return `${protocol}://${host}`
}

// استخدامه في الـ redirect
return NextResponse.redirect(new URL(next, getRedirectUrl(req)))
```

### الخطوة 3: التأكد من إعدادات الكوكيز للإنتاج
**الملف:** `src/lib/auth.ts`

**المشكلة:** الكوكيز قد لا تعمل في production إذا لم يكن `secure: true`.

**الحل:** التأكد من أن الكوكيز مضبوطة بشكل صحيح:
```typescript
cookieStore.set(ROLE_COOKIE_NAME, token, {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'lax',
  path: '/',
  maxAge: ROLE_COOKIE_DURATION,
  // لا نضع domain ليعمل على كل النطاقات
})
```

### الخطوة 4: التحقق من Supabase configuration
**الملف:** `src/lib/supabase/server.ts`

**المشكلة:** Supabase client قد لا يقرأ الكوكيز بشكل صحيح.

**الحل:** التأكد من أن Supabase client يستخدم الكوكيز بشكل صحيح:
```typescript
export async function createClient() {
  const cookieStore = await cookies()

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll()
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            )
          } catch {
            // Server Component — ignore
          }
        },
      },
    }
  )
}
```

## التحقق:

1. **على localhost:**

   - يجب أن يعمل

2. **على متصفح آخر:**
   - افتح `http://localhost:3000/?view=login`
   - سجّل دخول عبر Google
   - يجب أن يعمل أيضاً

3. **على Vercel:**
   - افتح `https://games-arabic.vercel.app/?view=login`
   - سجّل دخول عبر Google
   - يجب أن يعمل
